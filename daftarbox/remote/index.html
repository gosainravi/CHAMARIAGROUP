How it works

Both people run the same app. One shares, the other helps.

  1. Run Remote PCDownload and open REMOTE-PC.exe on both computers. Each one shows its own ID and password.
  2. Share your ID and passwordThe person who needs help reads them to the helper, who enters them under Control a remote computer and clicks Connect.
  3. Allow controlThe helper sees the screen. To use the mouse and keyboard they click Ask control — nothing happens until you click Allow.

Security

Built so that only the two computers in a session can see or control anything.

  • End-to-end encryptionScreen, mouse and keyboard data is encrypted with AES-256 on one PC and decrypted only on the other. Our server only ever passes along scrambled data.
  • Password never leaves your PCOnly a cryptographic proof is sent to check the password — the password itself is never sent to the server.
  • Tamper-proofEvery message is signed (HMAC-SHA256) and numbered. Altered, replayed or reordered data is rejected.
  • New keys every sessionEach session gets its own encryption keys from that session’s password and ID.
  • Locked to our serverThe app trusts only our server’s exact certificate, so no one can pretend to be it.
  • Your consent, every timeControl needs your Allow. Five wrong passwords lock your ID for 5 minutes.

How the encryption works

For IT teams who want the details.

  1. 1 · Secure connection to our serverEach app connects to our Mumbai server over TLS (wss). The app checks the server’s certificate against a fingerprint built into the app (certificate pinning), so a fake server or an interception proxy is refused.
  2. 2 · Password check without sending the passwordThe helper’s app turns the typed password into a proof using PBKDF2-HMAC-SHA256 (100,000 rounds, salted with both IDs). Only this proof travels; the other PC computes the same proof and compares it in constant time.
  3. 3 · Session keys on each PCBoth PCs derive four 256-bit keys from the session password and a unique session ID — again with PBKDF2-HMAC-SHA256 (100,000 rounds). Separate keys for each direction and for encryption vs. signing. The keys never leave the two PCs.
  4. 4 · Every message encrypted and signedEach screen frame, mouse move and key press is encrypted with AES-256-CBC (random IV per message) and then signed with HMAC-SHA256 over the whole message (encrypt-then-MAC). A sequence number and direction byte are signed too, so replayed, reordered or reflected messages are dropped.
  5. 5 · The server only relaysOur server pairs the two IDs, enforces the 40-minute limit and the 5-try lockout, and passes along encrypted bytes it cannot read. It never receives the password or the keys.

Stay safe from remote-access scams

Fraudsters pretend to be bank staff, police (“digital arrest”), courier or tech support and ask you to install a remote app.

  • Only share your ID and password with someone you know — such as your own company’s IT team.
  • Never allow control when someone calls you unexpectedly — real banks and police never ask for remote access.
  • Never open banking apps or type OTPs while someone else is connected.
  • Click End straight away if anything feels wrong. If you were cheated, call 1930 or report at cybercrime.gov.in.

Help

Opening Remote PC on a Mac (Beta)

1. Open the downloaded .dmg and drag Remote PC into Applications.
2. The first time, macOS may say it can’t check the app. Open System Settings → Privacy & Security, scroll down and click Open Anyway.
3. To share your screen, allow Screen Recording; to be controlled, allow Accessibility — the app has buttons that open the right settings. Then reopen Remote PC.
The Mac version works with the Windows version in both directions. It is in beta until it is notarized by Apple.

Windows says “Windows protected your PC” or “Unknown publisher”

Remote PC is new and not yet code-signed, so Windows shows this for any new app. Click More info → Run anyway.

Windows Firewall asks about network access

Click Allow. Remote PC needs internet access to connect to our server.

My antivirus removed the file

Some antivirus programs are cautious about new remote-control apps. Open Windows Security → Protection history, choose the Remote PC entry and select Restore, or ask your IT team. The file is scanned with Microsoft Defender before every release.

Email won’t let me send the app

Email services block .exe attachments. Send this page’s link instead, or the direct download link: github.com/gosainravi/CHAMARIAGROUP/releases/download/remote-pc-latest/REMOTE-PC.exe

The mouse or keyboard doesn’t work

The helper must click Ask control and you must click Allow. Windows also doesn’t let any normal app control administrator windows (such as Task Manager or installers).

The two computers won’t connect

Make sure both run the latest version from this page — older versions can’t connect to newer ones. Check the ID and password and that both show Ready.
